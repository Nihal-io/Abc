# Q7 – Library Management System (static pages)

**Question:** Design the following static web pages required for Library Management System web
site and link these pages to home page using hyperlinks in HTML. Home, About Us, List of Books.

## Files
| File | Purpose |
|------|---------|
| `index.html` | **Home** page – welcome text, quick-link cards, announcements. |
| `about.html` | **About Us** – history, facilities, rules, staff table. |
| `books.html` | **List of Books** – table of books (ID, title, author, subject, copies, availability). |
| `style.css` | Shared external stylesheet. |

Every page has the same navigation bar of `<a href="...">` hyperlinks (Home / About Us /
List of Books), plus a "Back to Home" link, so all pages are linked to the home page.

## How to run
Open `index.html` in a web browser and use the navigation bar to move between pages.
