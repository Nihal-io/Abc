# Q11 – College Website using HTML5 and CSS

**Question:** Develop College Website using HTML5 and CSS.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Home page – hero banner, campus `<figure>`, "Why choose us" cards, news `<article>`s. |
| `about.html` | About Us – vision/mission, leadership table, FAQ using `<details>/<summary>`. |
| `courses.html` | Courses offered table (`<thead>/<tbody>`, `rowspan`) and department highlights. |
| `contact.html` | Contact details and an **admission enquiry form using HTML5 input types**: `email`, `tel` (with `pattern`), `date`, `url`, `number`, `month`, `range` + `<output>`, `color`, `search`, `<datalist>`, plus `required`, `placeholder`, `autofocus`, `min/max`, `maxlength`. |
| `style.css` | External stylesheet (flexbox nav, CSS grid layout, responsive `@media` rule, form styling). |
| `images/logo.svg`, `images/campus.svg` | Local SVG images. |

## HTML5 semantic tags used
`<header>`, `<hgroup>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`,
`<figure>/<figcaption>`, `<time>`, `<mark>`, `<details>/<summary>`, `<datalist>`, `<output>`.

## How to run
Open `index.html` in a browser and navigate with the menu. On the Contact page, try submitting the
form with empty or invalid fields to see HTML5 validation; a valid submission shows a thank-you
message below the form.
