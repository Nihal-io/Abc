Types of CSS

1. External Style Sheet

This box is styled entirely by rules written in external.css, which is linked using the <link> tag. One external file can style a whole website.

  • Written in a separate .css file
  • Linked with <link rel="stylesheet" href="external.css">
  • Best for consistent look across many pages

2. Internal (Embedded) Style Sheet

This box is styled by rules written inside the <style> tag in the <head> section of this page. These rules apply only to this page.

3. Inline Style

This box uses the style attribute directly on each element. Inline styles affect only that one element.

This paragraph has the class external-box AND an inline style – the inline style wins (yellow background, black border).

Priority (Cascading Order)

When the same property is set in more than one place, the order of priority is: Inline > Internal / External (whichever comes later in the <head>) > Browser default. Example: h1 is green in external.css but blue in the internal sheet, and the heading appears blue.
