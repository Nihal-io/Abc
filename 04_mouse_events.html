Event Log

EventFires when
onmouseoverpointer moves onto the element (or a child)
onmouseoutpointer leaves the element (or a child)
onmouseenterpointer enters the element (does not bubble)
onmouseleavepointer leaves the element (does not bubble)
onmousedowna mouse button is pressed
onmouseupa mouse button is released
onmousemovepointer moves inside the element
onclickleft button pressed and released
ondblclickelement is double-clicked
