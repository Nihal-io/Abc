## Running
- **HTML/CSS/JS:** open the `.html` file in a browser. Pages that load XML (36-39) need a local server: `python3 -m http.server`.
- **PHP (37, 49a, 50):** `php -S localhost:8000` inside the folder (DB parts need MySQL + the folder's `db.sql`).
- **Servlets (44, 45, 48, 49b):** Tomcat 9 (`javax.servlet`); see each folder's README.
- **Database:** MySQL database `labdb`, user `root`, password `root` (change in the config files if yours differs).
